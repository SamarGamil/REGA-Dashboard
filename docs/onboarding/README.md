# دليل التعريف بمشروع REGA Dashboard (Onboarding)

> هذا الدليل مكتوب للمطوّر الجديد الذي يريد أن يفهم **الأعمال (Business)** أولاً ثم **الجانب التقني (Technical)**.
> الوثائق بالعربية، وأسماء الملفات والأكواد والمصطلحات التقنية بالإنجليزية كما هي في المشروع.
>
> المصدر الأساسي لكل معلومة هنا هو **الكود الحالي** (وليس الـ README القديمة). عند وجود تعارض بينهما ذكرناه في [10-gotchas-and-known-issues.md](./10-gotchas-and-known-issues.md).

## ما هو المشروع في سطرين؟

لوحة معلومات (Dashboard) عربية RTL تعمل كمنصة مؤشرات تنفيذية للهيئة العامة للعقار (REGA)، وتضم **منتجين**:

1. **مؤشرات الإيجار (Rental Indicators)** — مراقبة 14 مدينة سعودية وتصنيف حالة الضوابط الإيجارية لكل مدينة، مع تقارير PDF/Word.
2. **تملك الأجانب (Foreign Ownership)** — تحليلات صفقات التملك العقاري للأجانب (شراء/بيع/هبة) حسب المنطقة والجنسية ونوع العقار والمساحة والقيمة.

التقنية: واجهة **Angular 19** + واجهة برمجية **ASP.NET Core (.NET 10)**. لا توجد قاعدة بيانات: كل البيانات ملفات JSON/Excel تُحمَّل في الذاكرة عند الإقلاع.

## خطة التعلم خطوة بخطوة

الأيام تقريبية، والمهم هو **الترتيب**: الأعمال ثم التشغيل ثم المعمارية ثم التفاصيل. كل خطوة فيها «نشاط عملي» و«نقطة تحقق» لتتأكد أنك فهمت قبل الانتقال.

### الخطوة 0 — الصورة الكبيرة (30 دقيقة)

- اقرأ [01-business-overview.md](./01-business-overview.md) كاملاً.
- **نقطة تحقق:** هل تستطيع أن تشرح لزميل: ما المنتجان؟ من أين تأتي بياناتهما؟ ولماذا لا توجد قاعدة بيانات؟

### الخطوة 1 — افهم الأعمال قبل الكود (نصف يوم)

1. اقرأ [02-rental-controls-business.md](./02-rental-controls-business.md) ثم [03-foreign-ownership-business.md](./03-foreign-ownership-business.md).
2. أبقِ [04-glossary.md](./04-glossary.md) مفتوحاً في نافذة جانبية أثناء القراءة.
3. **نشاط:** اقرأ صفحة «منهجية التصنيف» داخل التطبيق نفسه (أو الملف [methodology.component.ts](../../Front/src/app/pages/rental-controls/methodology/methodology.component.ts)) وقارنها بما فهمته.
4. **نقطة تحقق:**
   - ما الفرق بين «نمو متسارع» و«نمو مرتفع» و«نمو مستدام»؟
   - ما المراحل التشغيلية الأربع لحالة المدينة؟
   - لماذا الأرقام في تملك الأجانب «مرجَّحة بالحصة» وليست عدّ صفوف؟

### الخطوة 2 — شغّل المشروع وتصفّحه (نصف يوم)

1. اتبع [09-local-setup-and-testing.md](./09-local-setup-and-testing.md) (انتبه لمشكلة الـ NuGet feed الخاصة ولقفل الملفات).
2. سجّل الدخول، وافتح **كل صفحة** في المنتجين، وغيّر الفترة (شهر/ربع) والفلاتر.
3. افتح Scalar على `http://localhost:5032/scalar/v1` وجرّب الـ endpoints.
4. **نشاط:** افتح DevTools → Network وشاهد أي طلبات تخرج عند فتح صفحة «حالة المدن» وصفحة «الملخص التنفيذي».
5. **نقطة تحقق:** سمِّ الطلبات التي تخرج لكل صفحة، وماذا يحدث عند تغيير الفترة؟

### الخطوة 3 — المعمارية (ساعتان)

- اقرأ [05-architecture.md](./05-architecture.md).
- **نقطة تحقق:** ارسم على ورقة: متصفح ← Angular ← API ← ملفات JSON، وحدّد أين تُحسب الأرقام، وأين يُخزَّن الـ JWT، وماذا يحدث عند إعادة تشغيل الـ API.

### الخطوة 4 — تتبّع ميزة واحدة من أولها لآخرها (يوم)

- اقرأ [11-how-to-trace-a-feature.md](./11-how-to-trace-a-feature.md) وطبّق وصفة التتبع على **«حالة المدن» (City Status)** ثم على **«الملخص التنفيذي» (Executive Summary)**.
- هذا أهم تمرين: يربط الأعمال بالواجهة بالـ API بالبيانات.

### الخطوة 5 — الـ Backend بعمق (يوم)

- اقرأ [06-backend-guide.md](./06-backend-guide.md).
- **نشاط:** ضع breakpoint في `RentalControlsPeriodService.ResolveAsync` وغيّر الفترة من الواجهة وشاهد كيف تُحلّ الفترة.
- **نقطة تحقق:** ما الفرق بين `IRentalControlsAggregationService` و`IRentalControlsPeriodService`؟ ولماذا يوجد `Recompute()`؟

### الخطوة 6 — الـ Frontend بعمق (يوم)

- اقرأ [07-frontend-guide.md](./07-frontend-guide.md).
- **نقطة تحقق:** كيف تختلف إدارة الحالة بين صفحات تملك الأجانب (`FilterStateService`) وصفحات الإيجار (`PortalPeriodService`)؟

### الخطوة 7 — البيانات والعمليات (نصف يوم، بحذر)

- اقرأ [08-data-and-operations.md](./08-data-and-operations.md).
- **تحذير:** أوامر الـ CLI تعدّل ملفات البيانات داخل المستودع. لا تشغّلها قبل أن تقرأ القسم وتأخذ نسخة احتياطية/تتأكد أن `git status` نظيف.
- **نقطة تحقق:** اشرح بخطواتك: كيف يُنشر شهر جديد؟ وكيف يُغلق ربع؟

### الخطوة 8 — الفخاخ والديون التقنية (ساعة)

- اقرأ [10-gotchas-and-known-issues.md](./10-gotchas-and-known-issues.md) قبل أن تبدأ بأي تعديل.

### الخطوة 9 — أول تعديل صغير

- اختر مهمة صغيرة من الأمثلة في [11-how-to-trace-a-feature.md](./11-how-to-trace-a-feature.md) (مثلاً: تغيير نص أو عتبة)، نفّذها، ثم شغّل الاختبارات المرتبطة.
