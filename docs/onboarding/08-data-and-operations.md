# 08 — البيانات والعمليات (Data & Operations)

> **تحذير:** هذه الأوامر **تكتب ملفات داخل المستودع** (`Back/AqarInsights.Api/Data/…`). قبل أي أمر: تأكد أن `git status` نظيف، واعمل على فرع منفصل، وراجع الـ diff بعد التنفيذ. لا تشغّل أمراً تشغيلياً على بيئة إنتاج/Staging دون اعتماد مالك البيانات.

## 1) جرد ملفات البيانات

كلها تحت [Back/AqarInsights.Api/Data/](../../Back/AqarInsights.Api/Data/) (المسارات قابلة للضبط، انظر `DataPaths.cs`):

| المسار | ما هو | يُقرأ/يُكتب بواسطة |
|---|---|---|
| `transactions.json` | صفقات تملك الأجانب (المخرج النهائي) | `--import` / `POST /api/import` يكتب؛ `DataLoaderService` يقرأ |
| `transactions.backup.json` | نسخة احتياطية قديمة | يدوي |
| `*.xlsx` في `Data/` | ملفات مصدر تملك الأجانب (أحدثها بوقت الكتابة هو المستخدم) | رفع/نسخ يدوي |
| `filter-options-updated.json` / `filter-options.json` | شجرة الفلاتر المنسَّقة | تُحرَّر يدوياً؛ `--normalize-data` يطبّعها |
| `users-accounts.json` | المستخدمون (`username`, `passwordHash`) | يدوي؛ يُقرأ عند الإقلاع |
| `rental-controls-source/` | **المصدر** للإيجار: ملفات Excel (لوحة المدن، تحليل لكل مدينة، شواغر، رصد إعلامي، فجوة العرض والطلب) + `city-reports/<city>.json` (نصوص التقارير) | `--apply-monthly-update` يعدّلها؛ `--import-controls` يقرأها |
| `rental-controls/tables/live/` | الإصدار الحي (جداول JSON + `release.json` + `source/` نسخة تدقيق) | `--import-controls` يكتب؛ الـ API يقرأ |
| `rental-controls/tables/<yyyy-Qn>/` | إصدار ربع مُغلق (مجمّد) | `--snapshot-controls` أو تجميد تلقائي عند بدء ربع جديد |
| `rental-controls/tables/monthly_movement.json` | صفوف حركة السوق الشهرية كما نُشرت | كل `--import-controls` يضيف/يستبدل صفوف الشهر الحي |
| `rental-controls/tables/corrections/<release>.json` | تصحيحات محروسة | يدوي |
| `reports/report-history.json` (أو مسار `Reports:HistoryFile`) | سجل التقارير المولَّدة | الـ API |

## 2) تملك الأجانب — تحديث البيانات

### الطريقة أ: من الواجهة/الـ API

`POST /api/import` (form-data، الحقل `file`، `.xlsx` حتى 30MB). الخادم:
1. يحفظ الملف في مجلد الإدخال (`DataSettings:InputDir`).
2. يشغّل `ConvertLatestAsync()` على **أحدث ملف بوقت الكتابة** (قد لا يكون الملف الذي رفعته إن كان هناك أحدث منه!).
3. عند النجاح: `Reload` ثم `Recompute` ثم إعادة تحميل الفلاتر، فتظهر الأرقام الجديدة **دون إعادة تشغيل**.
4. عند الفشل: `422` مع `ConversionReport` (أخطاء/تحذيرات).

`GET /api/import/inspect` يعرض أوراق وأعمدة أحدث ملف (مفيد لتشخيص قالب جديد).

> **انتبه:** أي مستخدم موثّق يستطيع الاستدعاء (لا توجد أدوار).

### الطريقة ب: CLI

```powershell
cd Back
dotnet run --project AqarInsights.Api --no-restore -- --import
```

(تفاصيل مشكلة الـ restore في [09](./09-local-setup-and-testing.md).) **انتبه:** على عكس بقية أوامر الـ CLI، فرع `--import` في [Program.cs](../../Back/AqarInsights.Api/Program.cs) لا ينفّذ `return` بعد النجاح؛ لذلك **يستمر البرنامج بعد الاستيراد في تحميل البيانات وتشغيل الخادم** (يخرج فقط عند الفشل). أوقفه بـ `Ctrl+C` عند انتهاء الاستيراد، وتحقق من هذا السلوك في الكود قبل الاعتماد عليه في سكربتات آلية.

### بعد الاستيراد

- راجع `ConversionReport`: عدد الصفوف الصالحة، التحذيرات (جنسيات `غير محدد`، مدن بلا منطقة…).
- افتح الواجهة وقارن آخر فترة وإجمالي الصفقات بما تتوقعه.
- شغّل `ForeignOwnershipGoldenTests`؛ إن تغيّرت البيانات عن قصد فالـ golden سيتغير، وتُعاد توليده بـ `FO_GOLDEN_REGEN=1` ثم يُراجَع الـ diff.

### `--normalize-data`

أداة لمرة واحدة تطبّع `transactions.json` وملفي الفلاتر وتدمج عقد الجغرافيا المكررة. ليست جزءاً من الاستيراد المعتاد.

## 3) مؤشرات الإيجار — دورة التحديث الشهري

**المبدأ:** العميل يرسل **مجلداً شهرياً**. نأخذ منه **القيم الشهرية فقط** إلى ملفات المصدر؛ أما البيانات الربعية فتتغير فقط مع ملفات الربع.

### الخطوات (مختصرة)

1. **جهّز:** فرع جديد، `git status` نظيف، ونسخة من مجلد التحديث المستلم.
2. **عدّل ملفات المصدر:**
   ```powershell
   dotnet run --project AqarInsights.Api --no-restore -- --apply-monthly-update --from <مجلد_التحديث> --month 2026-10
   # اختيارياً: --steps cpi,rental-vacancy,public-vacancy,media,gap
   ```
3. **راجع** كل `change` وكل `warning` في المخرجات، وافحص ملفات Excel التي تغيّرت (بـ `git diff` على الملفات الثنائية لن يفيد؛ افتحها). التعديل **غير ذري**: عند الفشل قد تكون بعض الملفات تغيّرت → استرجعها بـ git ثم أعد المحاولة.
4. **حدّث نصوص التقارير** إن لزم (`rental-controls-source/city-reports/<city>.json`). نصوص الفترة الخارجة تُستورد **قبل** إضافة ملفات الفترة التالية.
5. **انشر (استورد):**
   ```powershell
   dotnet run --project AqarInsights.Api --no-restore -- --import-controls
   ```
6. **راجع** تحذيرات الاستيراد (تناقض النصوص مع الأرقام، تصحيحات متقادمة).
7. **حدّث الـ golden** عن قصد: `RC_GOLDEN_REGEN=1` و`RC_PERIOD_GOLDEN_WRITE=1` ثم راجع الـ diff: **يجب أن تتغير القيم الشهرية فقط**.
8. **أعد تشغيل الـ API** ليقرأ الـ live الجديد.

### ماذا يأخذ كل `--steps`؟

| الخطوة | ملف التحديث | ملف المصدر المُعدَّل | ما يُؤخذ |
|---|---|---|---|
| `cpi` | `… تحليل مدينة <المدينة> ….xlsx` (14 ملفاً) | `تحليل مدينة <المدينة>_محدث.xlsx` | ورقة `مؤشرات CPI`، صفوف حركة السوق (CPI الإيجار، التضخم العام، التغير الإيجاري الشهري)، والاستنتاجان المقتبسان لها |
| `rental-vacancy` | ورقة `الشواغر الإيجارية` من نفس ملفات المدن | `مؤشرات المحددات الايجارية (الشواغر العامة).xlsx` | الأشهر الناقصة فقط (الموجودة تبقى؛ قيمة مختلفة = تحذير) |
| `public-vacancy` | `الشواغر العامة ….xlsx` (أسماء إنجليزية، كسر) | نفس ملف الشواغر، ورقة `الشواغر العامة- لم يعتمد` | كل شهر له نسبة (نسبة صحيحة، خانة عشرية) |
| `media` | `التحليل الشهري لانطباعات المواطنين ….pptx` | `الرصد الإعلامي.xlsx` | صفوف الشهر في الأوراق الثلاث (تُستبدل) |
| `gap` | `فجوة_العرض_والطلب_….xlsx` | `supply-demand-gap.xlsx` | الفجوة الفعلية الشهرية والعرض الفعلي = الطلب + الفجوة |

مدينة لا يبلغ تحديثها الشهر المطلوب (`--month`) تُتخطى بتحذير.

### فحوصات `--import-controls` (تمنع الكتابة عند الفشل)

- أحدث ربع في البيانات الجديدة **لا يجوز أن يكون أقدم** من ربع live الحالي.
- لا يجوز أن يختفي أي شهر يعرضه live في (الشواغر الإيجارية/العامة، الرصد، سلسلة CPI) — باستثناء أشهر داخل ربع مجمّد.
- وجود مجلد `city-reports` شرط؛ بدونه يفشل الاستيراد ولا يكتب شيئاً (حماية من فقدان النصوص).
- يحذّر إن ناقضت النصوص الأرقام المستوردة.

عندما تبدأ البيانات **ربعاً أحدث**، يُجمَّد live الخارج (صفوفه + `source/`) كإصدار لربعه تلقائياً (مرة واحدة إن لم يوجد).

## 4) إغلاق ربع وإنشاء Release

```powershell
dotnet run --project AqarInsights.Api --no-restore -- --snapshot-controls --period 2026-Q3
# اختيارياً: --from <releaseId> (الافتراضي live)  --source <مجلد_workbooks>  --commit <sha>  --force
```

- يرفض الكتابة فوق ربع موجود دون `--force` (ويحتفظ بملف corrections الخاص به حتى مع `--force`).
- يرفض فترة في المستقبل (يحمي من أخطاء تاريخ الملفات).
- الأرباع الشهرية القديمة لم تعد تُكتب؛ الأشهر تُخدَم من بيانات ربعها.
- **قاعدة:** لا تستخدم `--force` باستخفاف؛ فهو يعيد كتابة نشرة سبق اعتمادها.

## 5) Corrections (التصحيحات)

تصحيح بيانات إصدار **لا يتم بتعديل صفوف الإصدار**، بل بملف `corrections/<releaseId>.json` بصيغة:

```json
{ "id": "…", "table": "…", "match": { … }, "field": "…", "from": "…", "to": "…", "reason": "…", "date": "…" }
```
+ حقل `notes` نصي حر.

- يُطبَّق التصحيح عند تحميل الإصدار **فقط** إذا طابق `match` صفاً **واحداً** بالضبط، وكان `field` يساوي `from`؛ وإلا فهو «متقادم» (يُسجَّل ويُذكر في الاستيراد ولا يُطبَّق).
- يعيش خارج مجلد الإصدار فلا يضيع عند إعادة كتابته؛ وعند تجميد live يُنسخ تصحيحاته إلى الربع.
- مثال حقيقي: `tables/corrections/2026-Q2.json` (يصحّح أرقاماً مقتبسة في نصوص الربع الثاني).
- الـ README تحيل إلى مواصفة `docs/superpowers/specs/2026-11-02-release-storage-design.md`، **وهي غير موجودة في المستودع حالياً**.

## 6) نصوص تقارير المدن

- تُكتب في `rental-controls-source/city-reports/<cityId>.json` وتُستورد مع البيانات.
- بعد أي تعديل: `--import-controls`. اختبار `NarrativeSourceTests` يفشل حتى يطابق live الملفات.
- اختبارات الصياغة (`AllPeriodsWordingStandardsTests`, `ReportReferenceStandardsTests`, `NationalCityConsistencyTests`) تفحص اتساق الأرقام والمصطلحات في كل الفترات.

## 7) إدارة المستخدمين

الملف `users-accounts.json`: مصفوفة `{ "username": "...", "passwordHash": "<BCrypt>" }`.

1. ولّد hash بـ BCrypt (cost 11) لكلمة المرور، مثلاً من مشروع/سكربت مؤقت: `BCrypt.Net.BCrypt.HashPassword("<كلمة المرور>", 11)`.
2. أضف الكائن للملف.
3. **أعد تشغيل الـ API** (المستخدمون يُحمَّلون مرة واحدة عند الإقلاع؛ اسم المستخدم حساس لحالة الأحرف).
4. جرّب الدخول.

لا تضع كلمات مرور صريحة في أي ملف أو محادثة. والملف الحالي **مُتتبَّع في git** (انظر 10).
